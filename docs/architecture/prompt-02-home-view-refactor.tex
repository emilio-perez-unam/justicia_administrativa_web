\section{Scope Lock}

\section{Selected File}
\texttt{lib/app/views/home\_view.dart} was selected because it was the next known live-site hand-authored source file over 500 lines. The file mixed page composition, section-level layout, local view data, card hover behavior, route navigation, and animation details.

\section{Component Boundaries}
After the split, \texttt{HomeView} composes the homepage in route order: \texttt{HeroSection}, \texttt{HomeDualExpertiseSection}, and \texttt{HomePreviewCardsSection}. The dual expertise component owns the value-proposition layout and local pillar data. The preview cards component owns the responsive card grid, hover state, and route navigation.

\section{UI and UX Preservation}
The refactor preserves the existing brand language: navy and gold accents, serif headings, legal-and-technology positioning, hover motion, staggered fades, and desktop/tablet/mobile layout rules. No new font, palette, or generic SaaS visual treatment was introduced.

\section{Architecture Notes}
This is a presentation-only slice. DDD concepts are intentionally limited to preserving a clean page-composition boundary; no domain abstraction was introduced. OOP is used for small immutable, private view-data classes. No actor-model abstraction was needed because the slice has no asynchronous or concurrent workflow.
