\section*{Contact Ownership Audit}
The contact section was selected because the dirty and untracked contact files
formed one coherent site-local slice. \texttt{contact.dart} was already reduced
to section composition and referenced \texttt{contact/contact\_offices.dart}
and \texttt{contact/contact\_form.dart} as part files. Those part files held
the moved office and form code from the original contact component, with no
unrelated work detected.

\section*{Component Boundaries}
\begin{itemize}
  \item \texttt{contact.dart} remains the public contact composition boundary.
  \item \texttt{contact\_offices.dart} owns the hero, map treatment, office
  section heading, and responsive office-card grid.
  \item \texttt{contact\_section\_models.dart} owns private contact-section
  view data for office locations.
  \item \texttt{contact\_office\_card.dart} owns a single office card, contact
  detail rows, practice tags, and the office CTA.
  \item \texttt{contact\_form.dart} owns form state, validation flow,
  submission feedback, and reset behavior.
  \item \texttt{contact\_form\_fields.dart} owns local text input rendering and
  validation rules.
\end{itemize}

without changing the visible design.
