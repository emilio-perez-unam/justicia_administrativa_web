\section*{Messages Ownership Audit}
\texttt{messages\_view.dart} was selected because the file was dirty only with
coherent, message-specific, site-local changes. No existing
\texttt{portal/messages/**} files were present, so the extraction could proceed
without absorbing unrelated site-local work.

\section*{Component Boundaries}
\begin{itemize}
  \item \texttt{messages\_view.dart} remains the stateful page boundary. It
  owns selected-matter state, service calls, refresh behavior, current-user
  lookup, controller disposal, and toast feedback.
  \item \texttt{messages\_sidebar.dart} owns matter-list rendering, selected
  conversation affordances, and the sidebar empty state.
  \item \texttt{messages\_empty\_state.dart} owns the no-selection prompt.
  \item \texttt{messages\_thread\_panel.dart} owns the thread layout and
  composes the header, reversed message list, and composer.
  \item \texttt{messages\_thread\_header.dart} owns the selected matter title
  and voice/video call affordances.
  \item \texttt{messages\_composer.dart} owns the local message input surface.
  \item \texttt{message\_bubble.dart} owns sent/received bubble presentation,
  call-link styling, timestamp formatting, semantics, and animation.
\end{itemize}

\section*{UI and Accessibility}
The refactor preserved the portal message hierarchy, matter selection behavior,
conversation ordering, desktop/mobile split, composer layout, call actions,
animation behavior, and brand tokens. Semantic labels were kept local to
interactive conversation rows and message bubbles so screen-reader context
improves without adding visual clutter.

\section*{Architecture Notes}
This slice uses composition and presentational component extraction rather than
new domain abstractions. \texttt{Matter} and \texttt{PortalMessage} remain the
existing data contracts at the UI boundary. No new ADTs or global view models
were introduced. Actor-model abstractions were not needed: asynchronous side
effects are limited to \texttt{MessagesView} callbacks and remain explicit
through \texttt{PortalService}.
